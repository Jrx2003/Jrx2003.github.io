> 量化金融的数学语言——理解随机性和不确定性

---

## 为什么需要概率统计？

金融市场充满了**不确定性**：
- 明天的股价是多少？不知道，但可能有个范围
- 这个策略未来能盈利吗？不能保证，但可以说概率

**概率统计**就是量化处理这种不确定性的工具。

### 类比
- **确定性世界**：物理定律（抛出的球一定落地）
- **不确定性世界**：金融市场（股票可能涨可能跌）

量化投资就是在不确定性中寻找统计规律。

---

## 基础概念

### 随机变量

**随机变量**是一个取值不确定的变量。

**例子**：
- 明天的股价涨跌 → 随机变量 X
- 某股票的日收益率 → 随机变量 R
- 抛硬币的结果 → 随机变量 Y（正面=1，反面=0）

### 概率分布

**概率分布**描述随机变量取不同值的概率。

#### 离散型分布（取值可数）
**例子**：掷骰子
- P(X=1) = 1/6
- P(X=2) = 1/6
- ...
- P(X=6) = 1/6

#### 连续型分布（取值不可数）
**例子**：股票收益率
- 可以取 -10%, -9.99%, 0%, 5.5% 等任何实数值
- 用**概率密度函数**描述

### 正态分布（最重要）

正态分布（高斯分布）是金融中最常用的分布。

**特征**：
- 钟形曲线
- 对称
- 由均值(μ)和标准差(σ)决定

**公式**：
```
f(x) = (1/√(2πσ²)) * e^(-(x-μ)²/(2σ²))
```

**Python可视化**：
```python
import numpy as np
import matplotlib.pyplot as plt

# 生成正态分布数据
returns = np.random.normal(0.001, 0.02, 1000)  # 均值0.1%，标准差2%

plt.hist(returns, bins=50, density=True, alpha=0.7)
plt.title('Simulated Stock Returns Distribution')
plt.xlabel('Daily Return')
plt.ylabel('Density')
plt.show()
```

---

## 描述性统计

### 集中趋势度量

#### 1. 均值（Mean/Expected Value）

**算术均值**：
```
μ = (x₁ + x₂ + ... + xₙ) / n
```

**在金融中**：
- 平均收益率：策略的长期表现
- 例子：某策略过去20天收益率平均为0.5%

**Python计算**：
```python
import numpy as np

returns = np.array([0.01, -0.02, 0.015, 0.005, -0.01])
mean_return = np.mean(returns)
print(f"平均收益率: {mean_return:.4f}")  # 0.0000
```

#### 2. 中位数（Median）

排序后位于中间的值，不受极端值影响。

```python
median = np.median(returns)
```

#### 3. 众数（Mode）

出现频率最高的值。

### 离散程度度量

#### 1. 方差（Variance）

衡量数据与均值的偏离程度。

```
σ² = Σ(xᵢ - μ)² / n
```

**在金融中**：
- 方差越大 = 波动越大 = 风险越大

#### 2. 标准差（Standard Deviation）

方差的平方根，与原始数据同单位。

```
σ = √σ²
```

**Python计算**：
```python
volatility = np.std(returns)
print(f"收益率标准差: {volatility:.4f}")

# 年化波动率（假设日数据）
annual_vol = volatility * np.sqrt(252)
print(f"年化波动率: {annual_vol:.2%}")
```

#### 3. 分位数（Quantiles）

将数据分成等份的临界点。

**常用分位数**：
- 中位数 = 50%分位数
- 25%分位数（第一四分位数）
- 75%分位数（第三四分位数）

**VaR（风险价值）**就是基于分位数：
```python
# 计算95% VaR（日度）
var_95 = np.percentile(returns, 5)
print(f"95% VaR: {var_95:.2%}")  # 意思是：有5%的概率亏损超过这个值
```

## 金融中的重要分布

### 1. 正态分布的应用

**假设**：股票收益率服从正态分布

**如果日收益率 ~ N(μ, σ²)**：
- 约68%的概率在 μ ± σ 范围内
- 约95%的概率在 μ ± 2σ 范围内
- 约99.7%的概率在 μ ± 3σ 范围内

**例子**：
```
日收益率 ~ N(0.1%, 2%)
- 68%概率：在 -1.9% 到 +2.1% 之间
- 95%概率：在 -3.9% 到 +4.1% 之间
```

**Python验证**：
```python
# 计算实际落在1个标准差内的比例
within_1std = np.sum(np.abs(returns - mean_return) < volatility) / len(returns)
print(f"在1个标准差内的比例: {within_1std:.2%}")
# 理论上应该是68%
```

### 2. 收益率的分布特征

实际金融数据往往**不**完全符合正态分布：

| 特征 | 正态分布 | 实际收益率 |
|------|----------|-----------|
| 对称性 | 完全对称 | 轻微左偏 |
| 峰度 | 3（常数） | >3（肥尾） |
| 极值概率 | 可预测 | 比预期更频繁 |

**肥尾（Fat Tails）**：极端事件（暴涨暴跌）比正态分布预测的更频繁。

## 统计推断

### 样本 vs 总体

- **总体**：所有可能的观测值（无法完全获取）
- **样本**：实际观测到的数据

我们用**样本统计量**估计**总体参数**。

### 中心极限定理

**重要结论**：
无论总体分布如何，样本均值的分布趋近于正态分布。

**意义**：
即使单个收益率不是正态分布，一段时间的平均收益率近似正态分布。

### 假设检验

#### 基本逻辑
1. 提出原假设 H₀（比如：策略收益为0）
2. 收集数据计算统计量
3. 计算p值（在H₀成立时，观察到当前数据的概率）
4. 如果p值 < 0.05，拒绝H₀

#### 例子：检验策略是否显著盈利
```python
from scipy import stats

# 模拟30天的策略收益率
strategy_returns = np.random.normal(0.001, 0.01, 30)

# 单样本t检验：均值是否显著大于0
t_stat, p_value = stats.ttest_1samp(strategy_returns, 0)

print(f"t统计量: {t_stat:.4f}")
print(f"p值: {p_value:.4f}")

if p_value < 0.05:
    print("在5%显著性水平下，策略收益显著不为0")
else:
    print("无法拒绝收益为0的假设")
```

### 相关性

#### 协方差
衡量两个变量共同变化的程度。
```python
covariance = np.cov(returns_a, returns_b)[0, 1]
```

#### 相关系数
协方差标准化后的值，范围[-1, 1]。

```python
correlation = np.corrcoef(returns_a, returns_b)[0, 1]
```

**解释**：
- 1：完全正相关（同涨同跌）
- -1：完全负相关（此消彼长）
- 0：无线性相关

**在金融中**：
- 低相关性资产组合可降低风险
-  pairs trading 寻找高相关性股票对

## 实战：策略绩效评估

```python
import numpy as np
from scipy import stats

# 模拟策略收益率数据（252个交易日）
np.random.seed(42)
strategy_returns = np.random.normal(0.0008, 0.015, 252)  # 日均0.08%，波动1.5%
benchmark_returns = np.random.normal(0.0005, 0.012, 252)  # 基准

# 1. 收益指标
total_return = (1 + strategy_returns).prod() - 1
annual_return = (1 + total_return) ** (252/252) - 1
avg_daily_return = np.mean(strategy_returns)

print("=== 收益指标 ===")
print(f"总收益率: {total_return:.2%}")
print(f"年化收益率: {annual_return:.2%}")
print(f"日均收益率: {avg_daily_return:.4f}")

# 2. 风险指标
volatility = np.std(strategy_returns)
annual_vol = volatility * np.sqrt(252)
print("\n=== 风险指标 ===")
print(f"日波动率: {volatility:.4f}")
print(f"年化波动率: {annual_vol:.2%}")

# 最大回撤
cumulative = (1 + strategy_returns).cumprod()
peak = np.maximum.accumulate(cumulative)
drawdown = (cumulative - peak) / peak
max_drawdown = np.min(drawdown)
print(f"最大回撤: {max_drawdown:.2%}")

# 3. 风险调整收益
sharpe_ratio = (avg_daily_return - 0.0001) / volatility * np.sqrt(252)  # 假设无风险利率0.01%
print("\n=== 风险调整收益 ===")
print(f"夏普比率: {sharpe_ratio:.4f}")

# 4. 统计显著性
t_stat, p_value = stats.ttest_1samp(strategy_returns, 0)
print("\n=== 统计检验 ===")
print(f"t统计量: {t_stat:.4f}")
print(f"p值: {p_value:.4f}")
print(f"收益显著性: {'显著' if p_value < 0.05 else '不显著'} (5%水平)")

# 5. 分布特征
skewness = stats.skew(strategy_returns)
kurtosis = stats.kurtosis(strategy_returns)
print("\n=== 分布特征 ===")
print(f"偏度: {skewness:.4f} ({'左偏' if skewness < 0 else '右偏'})")
print(f"峰度: {kurtosis:.4f} ({'尖峰' if kurtosis > 0 else '平峰'})")
```

## 关键概念总结

| 概念 | 定义 | 金融意义 |
|------|------|----------|
| 期望（均值） | E[X] | 预期收益 |
| 方差 | Var(X) | 风险（波动） |
| 标准差 | σ = √Var(X) | 波动率 |
| 夏普比率 | (E[R] - Rf) / σ | 风险调整收益 |
| VaR | 分位数 | 潜在损失 |
| 相关系数 | ρ | 分散化效果 |
| p值 | P(数据\|H₀) | 统计显著性 |

## 为什么需要概率统计？

金融市场充满了**不确定性**：
- 明天的股价是多少？不知道，但可能有个范围
- 这个策略未来能盈利吗？不能保证，但可以说概率

**概率统计**就是量化处理这种不确定性的工具。

### 类比
- **确定性世界**：物理定律（抛出的球一定落地）
- **不确定性世界**：金融市场（股票可能涨可能跌）

量化投资就是在不确定性中寻找统计规律。

---

## 基础概念

### 随机变量

**随机变量**是一个取值不确定的变量。

**例子**：
- 明天的股价涨跌 → 随机变量 X
- 某股票的日收益率 → 随机变量 R
- 抛硬币的结果 → 随机变量 Y（正面=1，反面=0）

### 概率分布

**概率分布**描述随机变量取不同值的概率。

#### 离散型分布（取值可数）
**例子**：掷骰子
- P(X=1) = 1/6
- P(X=2) = 1/6
- ...
- P(X=6) = 1/6

#### 连续型分布（取值不可数）
**例子**：股票收益率
- 可以取 -10%, -9.99%, 0%, 5.5% 等任何实数值
- 用**概率密度函数**描述

### 正态分布（最重要）

正态分布（高斯分布）是金融中最常用的分布。

**特征**：
- 钟形曲线
- 对称
- 由均值(μ)和标准差(σ)决定

**公式**：
```
f(x) = (1/√(2πσ²)) * e^(-(x-μ)²/(2σ²))
```

**Python可视化**：
```python
import numpy as np
import matplotlib.pyplot as plt

# 生成正态分布数据
returns = np.random.normal(0.001, 0.02, 1000)  # 均值0.1%，标准差2%

plt.hist(returns, bins=50, density=True, alpha=0.7)
plt.title('Simulated Stock Returns Distribution')
plt.xlabel('Daily Return')
plt.ylabel('Density')
plt.show()
```

## 描述性统计

### 集中趋势度量

#### 1. 均值（Mean/Expected Value）

**算术均值**：
```
μ = (x₁ + x₂ + ... + xₙ) / n
```

**在金融中**：
- 平均收益率：策略的长期表现
- 例子：某策略过去20天收益率平均为0.5%

**Python计算**：
```python
import numpy as np

returns = np.array([0.01, -0.02, 0.015, 0.005, -0.01])
mean_return = np.mean(returns)
print(f"平均收益率: {mean_return:.4f}")  # 0.0000
```

#### 2. 中位数（Median）

排序后位于中间的值，不受极端值影响。

```python
median = np.median(returns)
```

#### 3. 众数（Mode）

出现频率最高的值。

### 离散程度度量

#### 1. 方差（Variance）

衡量数据与均值的偏离程度。

```
σ² = Σ(xᵢ - μ)² / n
```

**在金融中**：
- 方差越大 = 波动越大 = 风险越大

#### 2. 标准差（Standard Deviation）

方差的平方根，与原始数据同单位。

```
σ = √σ²
```

**Python计算**：
```python
volatility = np.std(returns)
print(f"收益率标准差: {volatility:.4f}")

# 年化波动率（假设日数据）
annual_vol = volatility * np.sqrt(252)
print(f"年化波动率: {annual_vol:.2%}")
```

#### 3. 分位数（Quantiles）

将数据分成等份的临界点。

**常用分位数**：
- 中位数 = 50%分位数
- 25%分位数（第一四分位数）
- 75%分位数（第三四分位数）

**VaR（风险价值）**就是基于分位数：
```python
# 计算95% VaR（日度）
var_95 = np.percentile(returns, 5)
print(f"95% VaR: {var_95:.2%}")  # 意思是：有5%的概率亏损超过这个值
```

## 金融中的重要分布

### 1. 正态分布的应用

**假设**：股票收益率服从正态分布

**如果日收益率 ~ N(μ, σ²)**：
- 约68%的概率在 μ ± σ 范围内
- 约95%的概率在 μ ± 2σ 范围内
- 约99.7%的概率在 μ ± 3σ 范围内

**例子**：
```
日收益率 ~ N(0.1%, 2%)
- 68%概率：在 -1.9% 到 +2.1% 之间
- 95%概率：在 -3.9% 到 +4.1% 之间
```

**Python验证**：
```python
# 计算实际落在1个标准差内的比例
within_1std = np.sum(np.abs(returns - mean_return) < volatility) / len(returns)
print(f"在1个标准差内的比例: {within_1std:.2%}")
# 理论上应该是68%
```

### 2. 收益率的分布特征

实际金融数据往往**不**完全符合正态分布：

| 特征 | 正态分布 | 实际收益率 |
|------|----------|-----------|
| 对称性 | 完全对称 | 轻微左偏 |
| 峰度 | 3（常数） | >3（肥尾） |
| 极值概率 | 可预测 | 比预期更频繁 |

**肥尾（Fat Tails）**：极端事件（暴涨暴跌）比正态分布预测的更频繁。

## 统计推断

### 样本 vs 总体

- **总体**：所有可能的观测值（无法完全获取）
- **样本**：实际观测到的数据

我们用**样本统计量**估计**总体参数**。

### 中心极限定理

**重要结论**：
无论总体分布如何，样本均值的分布趋近于正态分布。

**意义**：
即使单个收益率不是正态分布，一段时间的平均收益率近似正态分布。

### 假设检验

#### 基本逻辑
1. 提出原假设 H₀（比如：策略收益为0）
2. 收集数据计算统计量
3. 计算p值（在H₀成立时，观察到当前数据的概率）
4. 如果p值 < 0.05，拒绝H₀

#### 例子：检验策略是否显著盈利
```python
from scipy import stats

# 模拟30天的策略收益率
strategy_returns = np.random.normal(0.001, 0.01, 30)

# 单样本t检验：均值是否显著大于0
t_stat, p_value = stats.ttest_1samp(strategy_returns, 0)

print(f"t统计量: {t_stat:.4f}")
print(f"p值: {p_value:.4f}")

if p_value < 0.05:
    print("在5%显著性水平下，策略收益显著不为0")
else:
    print("无法拒绝收益为0的假设")
```

### 相关性

#### 协方差
衡量两个变量共同变化的程度。
```python
covariance = np.cov(returns_a, returns_b)[0, 1]
```

#### 相关系数
协方差标准化后的值，范围[-1, 1]。

```python
correlation = np.corrcoef(returns_a, returns_b)[0, 1]
```

**解释**：
- 1：完全正相关（同涨同跌）
- -1：完全负相关（此消彼长）
- 0：无线性相关

**在金融中**：
- 低相关性资产组合可降低风险
-  pairs trading 寻找高相关性股票对

## 实战：策略绩效评估

```python
import numpy as np
from scipy import stats

# 模拟策略收益率数据（252个交易日）
np.random.seed(42)
strategy_returns = np.random.normal(0.0008, 0.015, 252)  # 日均0.08%，波动1.5%
benchmark_returns = np.random.normal(0.0005, 0.012, 252)  # 基准

# 1. 收益指标
total_return = (1 + strategy_returns).prod() - 1
annual_return = (1 + total_return) ** (252/252) - 1
avg_daily_return = np.mean(strategy_returns)

print("=== 收益指标 ===")
print(f"总收益率: {total_return:.2%}")
print(f"年化收益率: {annual_return:.2%}")
print(f"日均收益率: {avg_daily_return:.4f}")

# 2. 风险指标
volatility = np.std(strategy_returns)
annual_vol = volatility * np.sqrt(252)
print("\n=== 风险指标 ===")
print(f"日波动率: {volatility:.4f}")
print(f"年化波动率: {annual_vol:.2%}")

# 最大回撤
cumulative = (1 + strategy_returns).cumprod()
peak = np.maximum.accumulate(cumulative)
drawdown = (cumulative - peak) / peak
max_drawdown = np.min(drawdown)
print(f"最大回撤: {max_drawdown:.2%}")

# 3. 风险调整收益
sharpe_ratio = (avg_daily_return - 0.0001) / volatility * np.sqrt(252)  # 假设无风险利率0.01%
print("\n=== 风险调整收益 ===")
print(f"夏普比率: {sharpe_ratio:.4f}")

# 4. 统计显著性
t_stat, p_value = stats.ttest_1samp(strategy_returns, 0)
print("\n=== 统计检验 ===")
print(f"t统计量: {t_stat:.4f}")
print(f"p值: {p_value:.4f}")
print(f"收益显著性: {'显著' if p_value < 0.05 else '不显著'} (5%水平)")

# 5. 分布特征
skewness = stats.skew(strategy_returns)
kurtosis = stats.kurtosis(strategy_returns)
print("\n=== 分布特征 ===")
print(f"偏度: {skewness:.4f} ({'左偏' if skewness < 0 else '右偏'})")
print(f"峰度: {kurtosis:.4f} ({'尖峰' if kurtosis > 0 else '平峰'})")
```

## 关键概念总结

| 概念 | 定义 | 金融意义 |
|------|------|----------|
| 期望（均值） | E[X] | 预期收益 |
| 方差 | Var(X) | 风险（波动） |
| 标准差 | σ = √Var(X) | 波动率 |
| 夏普比率 | (E[R] - Rf) / σ | 风险调整收益 |
| VaR | 分位数 | 潜在损失 |
| 相关系数 | ρ | 分散化效果 |
| p值 | P(数据\|H₀) | 统计显著性 |
