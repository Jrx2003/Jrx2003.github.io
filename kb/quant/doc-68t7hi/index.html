股票与股票市场

股权投资的基石——理解股票的运作机制

什么是股票？

股票代表对公司的所有权份额。

股东的权利

权利说明
分红权获得公司利润分配
投票权参与公司重大决策
剩余财产权公司清算时获得剩余资产
转让权买卖股票

股票类型

普通股 vs 优先股

特征普通股优先股
分红不固定，与公司业绩挂钩固定股息率
投票权有通常无
风险较高较低
求偿顺序最后优先于普通股

股票市场结构

一级市场 vs 二级市场

┌─────────────┐      IPO/增发      ┌─────────────┐      交易      ┌─────────────┐
│   发行人    │ ─────────────────→ │  一级市场   │ ─────────────→ │  二级市场   │
│  (公司)    │   首次公开发行    │  (发行市场)  │   投资者间买卖  │  (交易市场)  │
└─────────────┘                    └─────────────┘                └─────────────┘

一级市场：公司向公众发售新股

  • IPO（首次公开发行）
  • 增发
  • 配股

二级市场：投资者之间的交易

  • 交易所市场
  • 场外市场（OTC）

股票交易机制

订单类型

订单类型说明使用场景
市价单以当前市场价格立即成交追求成交速度
限价单以指定价格或更好价格成交控制成交价格
止损单价格达到止损价时转为市价单风险控制
止损限价价格达到止损价时转为限价单控制止损价格

价格形成机制

集合竞价（开盘、收盘）：

  • 一段时间内接受订单
  • 以最大成交量原则确定开盘价/收盘价

连续竞价（交易时段）：

  • 价格优先、时间优先
  • 实时撮合

股票指数

什么是指数？

股票指数是衡量一组股票整体表现的指标。

主要A股指数

指数成分股特点
上证指数上交所所有股票大盘代表性
深证成指深交所代表性股票成长风格
沪深300沪深两市300只大盘股蓝筹代表
中证500沪深300之后的500只中盘股中小盘
创业板指创业板代表性股票高成长、高风险
科创50科创板50只龙头科技创新

指数市场说明

指数计算方法

价格加权：

指数 = Σ股价 / 除数
  • 例子：道琼斯工业指数

市值加权：

指数 = Σ(股价 × 股本) / 基期市值 × 基期指数
  • 例子：沪深300、S&P 500

等权：每只股票权重相同

股票估值基础

市盈率（P/E）

P/E = 股价 / 每股收益（EPS）

解读：

  • P/E = 20：投资者愿意为公司每1元盈利支付20元
  • 高P/E：成长预期高或估值偏高
  • 低P/E：可能被低估或前景不佳

P/E类型：

类型计算方式特点
静态P/E股价/上一年EPS滞后
动态P/E股价/预测EPS前瞻但不确定
TTM P/E股价/过去四个季度EPS最常用

市净率（P/B）

P/B = 股价 / 每股净资产

适用场景：

  • 银行股、周期股
  • 资产重的行业

市销率（P/S）

P/S = 市值 / 营业收入

适用场景：

  • 亏损企业
  • 成长期公司

股息率

股息率 = 年度股息 / 股价

意义：

  • 价值投资指标
  • 现金流回报

Python估值计算

import pandas as pd

def calculate_valuation_metrics(price, eps, book_value, sales, dividend):
    """
    计算估值指标
    """
    metrics = {
        'PE_TTM': price / eps,
        'PB': price / book_value,
        'PS': price / sales,
        'Dividend_Yield': dividend / price
    }
    return metrics

# 示例
stock_data = {
    'price': 50,
    'eps': 2.5,
    'book_value': 15,
    'sales': 20,
    'dividend': 1.0
}

metrics = calculate_valuation_metrics(**stock_data)
for k, v in metrics.items():
    print(f"{k}: {v:.2f}")

股票收益率

收益率计算

简单收益率：

R_t = (P_t - P_{t-1}) / P_{t-1}

对数收益率：

r_t = ln(P_t / P_{t-1})

多期收益率：

总收益率 = (1+R_1)(1+R_2)...(1+R_n) - 1

收益率分布特征

特征描述
肥尾极端收益比正态分布更频繁
偏度通常左偏（下跌更剧烈）
波动聚集大波动后跟着大波动
杠杆效应下跌时波动率上升

1. 选股因子

因子类型具体指标逻辑

2. 行业轮动

def sector_rotation_signal(sector_returns, lookback=20):
    """
    行业轮动信号
    买入近期表现好的行业
    """
    momentum = sector_returns.iloc[-lookback:].mean()
    ranking = momentum.rank(ascending=False)
    signal = (ranking <= 3).astype(int)  # 前3名
    return signal

3. 多因子模型

def calculate_factor_scores(stock_data):
    """
    计算多因子得分
    """
    # 价值因子：PE倒数
    value_score = 1 / stock_data['PE']

    # 质量因子：ROE
    quality_score = stock_data['ROE']

    # 动量因子：过去20日收益
    momentum_score = stock_data['return_20d']

    # 标准化并综合
    total_score = (standardize(value_score) +
                   standardize(quality_score) +
                   standardize(momentum_score)) / 3

    return total_score

def standardize(series):
    """Z-score标准化"""
    return (series - series.mean()) / series.std()
